MyEventTarget Demo

这个 demo 用简化代码模拟浏览器事件系统的核心：监听器记录、事件对象内部标志位、捕获、目标、冒泡、默认行为取消、一次性监听、被动监听和 AbortSignal 清理。

root capture listener / bubble listener
parent capture listener / bubble listener / signal listener
child target listener / once listener / passive listener
打开 my-event-target-demo/app.js 阅读源码更清楚。点击主按钮时，事件会从 root 捕获到 child，再从 child 冒泡回 root。 preventDefault() 会让 dispatchEvent() 返回 false。
